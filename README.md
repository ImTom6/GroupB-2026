# Repository for GroupB-2026 Project
- OriginalPipeline contains all coded used to follow the original paper pipeline.
- ScanPy alternate pipeline contains all code required to run the ScanPy sections of the alternative pipeline
- ShinyApp contains app.R. All necessary files can be found on LAMP.


- All large files that are not directly used on the shiny server are stored within lamp (ShinyApp/files/additional_files).

- This project follows the work of Camp, J.G. et al. (2015). Human cerebral organoids recapitulate gene expression programs of fetal neocortex development. PNAS, 112(51), pp.15672–15677.
